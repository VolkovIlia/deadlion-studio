# Deadlion Studio 4.6.0 engineering report

1. **Starting point.** Local and upstream Deadlion `main` resolved to `25620d1f53d9982de19625ff199bb3591615d620`. The test host ran Fedora 44. OMP 19.2.1 was installed. The OMP 19.2.0 binary was checked against its published SHA256. [4.5.0 source](https://github.com/VolkovIlia/deadlion-studio/commit/25620d1f53d9982de19625ff199bb3591615d620) · [OMP releases](https://github.com/can1357/oh-my-pi/releases)
2. **Confirmed 4.5.0 defects.** Live RPC blocked “Explain the algorithm without changing files” with an empty diff. Another run returned `VERIFIED` for an unrelated Python change when the only workload checked `candidate`. Two opaque-tool scans returned the same eight of nine paths. Code inspection confirmed a hard version check, manual trust policy, missing live CI jobs and absence of durable refactoring milestones. [Live regressions](../tests/omp_engineering_smoke.py) · [Queue regression](../tests/test_readiness_omp.mjs)
3. **Corrections.** Scoped receipts, fresh RPC revalidation, intent-based routing, explicit lifecycle transitions, fair incremental scheduling, passive setup and refactoring checkpoints use existing OMP entry points. [Gate](../plugins/deadlion/omp/gate.mjs) · [Controller](../plugins/deadlion/omp/performance.mjs) · [Launcher](../plugins/deadlion/omp/dl-omp)
4. **Audit claims narrowed by testing.** 4.5.0 already rejected failed oracles, detected contract changes, exercised native subagents and resumed isolated Autoresearch. Its Engineering Smoke passed when supplied with ast-grep. Existing clangd and targeted pylsp paths were reused. [4.5.0 evidence](omp-engineering.md) · [Evolution smoke](../tests/omp_engineering_evolution.py)
5. **Classification.** Action patterns initialize intent. Actual changes, configured sensitive paths and component scope refine the route. An empty diff permits read-only requests to finish without changed-code checks. A Python comment-only edit can demonstrate unchanged AST and shebang against the pinned baseline. General population accuracy and false-heavy activation rates remain unmeasured. [Classifier](../plugins/deadlion/omp/evidence.mjs) · [Routing tests](../tests/test_readiness_omp.mjs)
6. **Automatic setup.** Passive discovery inspects manifests and installed tools. Setup pins approval to the reported project configuration. The Makefile fixture verifies detection without running its embedded command and revocation when it changes. [Discovery](../plugins/deadlion/omp/capabilities.py) · [Setup tests](../tests/test_readiness_omp.mjs)
7. **Computer Science by default.** Standard mode includes structural and performance hints. Python AST analysis can run without Ruff. Targeted semantic context retains its provenance. Unavailable mandatory analyzers prevent acceptance. [Analyzer](../plugins/deadlion/skills/performance/scripts/dl-analyze) · [Diagnostics](../plugins/deadlion/omp/diagnostics.mjs)
8. **Compatibility.** Live checks exercise OMP 19.2.1 and 19.2.0 for Core, Lifecycle, Quality Gate, RPC, Subagents and Evolution. LSP is partially verified. Unknown versions retain discovery and report mandatory enforcement as unverified. [Capability matrix](omp-4.6.md#compatibility)
9. **Scope-aware verification.** Each accepted workload oracle is bound to declared candidate files. Functional receipts need an approved scope. Shared interfaces conservatively expand across discovered component roots. Approved inputs and receipts carry digests and are checked against current state. [Coverage](../plugins/deadlion/omp/coverage.mjs) · [Gate](../plugins/deadlion/omp/gate.mjs)
10. **Large-scale refactoring.** An approved workflow plan becomes a validated DAG. The global baseline retains original source identity and the tracked dirty patch. Each accepted stage has its own checkpoint. The final gate tests cumulative changes against the original baseline. The fixture reconciles an operator commit between milestones and checks that a later change invalidates the comparison. [Implementation](../plugins/deadlion/omp/refactor.mjs) · [Live scenario](../tests/omp_refactoring_smoke.py)
11. **Ratchet.** File lines, measurable function sizes, SLOC and dependency counts are compared with the stage baseline. New and worsened violations fail. Functional and approved resource requirements are checked separately. [Measurement](../plugins/deadlion/omp/structural.py) · [Tests](../tests/test_readiness_omp.mjs)
12. **Cross-session state.** OMP session entries bind transitions and milestones to persistent task state. Resume retains the baseline, deadline and budget. External changes invalidate the checkpoint or final comparison. [Lifecycle](../plugins/deadlion/omp/performance.mjs)
13. **Subagents.** Native task and parallel eval fixtures verify child attribution and parent checks. Milestone path assignments reject overlap and restrict editing and opaque tools. Delegated worktree integration and rollback remain unverified. [Live fixtures](../tests/omp_engineering_smoke.py) · [Refactoring ownership](../plugins/deadlion/omp/refactor.mjs)
14. **Semantics.** clangd confirmed C and C++ issues, the TypeScript server reported diagnostic 2322 and Python pylsp supplied type context. Rust, Go, Java and Kotlin LSP and automatic cross-language dependency traversal remain unverified. [C++ and TypeScript probes](../tests/omp_lsp_matrix.py) · [Python hover fixture](../tests/omp_engineering_smoke.py)
15. **Plugin overhead.** The incremental cursor advances past a persistent prefix. Strict snapshots reuse directory validations and hash file contents. A 4.6 development startup probe using the scripted provider had medians of 498 ms at 12 files and 934 ms at 10,000 with the plugin enabled, versus 307 ms and 313 ms with extensions disabled. The older 4.5 probe ran under different host conditions, including different disabled medians. [Raw samples](omp-4.6-measurements.json)
16. **Scaling.** Five paired strict snapshot runs per size used a mixed-language fixture with a 16 MiB binary and a large text file. The benchmark requires equality of output JSON and records peak RSS. Standalone phase metrics for LSP, analyzers, cold cache and subprocesses are incomplete.
