# Getting help

| You want to | Go to |
|---|---|
| ask how to use a skill or tool | [Discussions → Q&A](https://github.com/VolkovIlia/deadlion-studio/discussions/categories/q-a) |
| report something that is broken | [a bug report](https://github.com/VolkovIlia/deadlion-studio/issues/new?template=01-bug-report.yml) |
| suggest a skill, tool or change | [a feature request](https://github.com/VolkovIlia/deadlion-studio/issues/new?template=02-feature-request.yml) |
| report a security problem | [`SECURITY.md`](SECURITY.md), never a public issue |

Before you ask, check the [README](README.md) and the skill's own `SKILL.md`; every tool
also prints its usage when run with a wrong argument.
