# Теория катастроф: модель «скоростной инновации»

Читай этот файл на Шаге 3, когда задача про развитие системы (фирма, продукт,
рынок, процесс), а не про точечный дефект. Метод связывает АРИЗ с математической
теорией катастроф и моделирует **скачок** развития, а не плавное улучшение.

## Что такое катастрофа

Катастрофа — скачкообразное изменение системы как внезапный ответ на **плавное**
изменение внешних/внутренних условий (управляющих параметров). Система переходит
из одного устойчивого стационарного состояния в другое. Как идёт переходный
процесс — для модели неважно; важны числа и качество состояний равновесия.

## Катастрофа типа «сборка»

В изобретательских и экономических задачах используется каноническая катастрофа
**«сборка»** с потенциальной функцией двух управляющих параметров λ и μ:

```
E(x, λ, μ) = x⁴/4 + λ·x²/2 + μ·x
```

- **x** — координата катастрофы (то, влияние на что исследуем: выпуск, вероятность
  аварии, состояние изделия и т.п.);
- **λ** — обычно «внутренний» параметр (напряг/мощность/интенсивность процесса);
- **μ** — обычно «внешний» параметр (влияние среды).

Поведение:
- при λ<0 — одна устойчивая яма (одно решение, докритическая область);
- при λ=0 — катастрофа: появляются **две устойчивые ямы** и **холм неустойчивости**
  между ними;
- параметр μ наклоняет рельеф: при росте μ одна яма мельчает и при критическом
  μ_кр = √(−4λ³/27) исчезает — снова одно состояние.

**Образ:** «шарик» в левой яме — старое решение/прототип; в момент катастрофы он
перекатывается в правую яму — новое решение. Это инсайт, «озарение», скачок.

**Связь с АРИЗ:** левая яма = минимум вреда в ТП-1, правая = минимум вреда в ТП-2;
потенциальная функция = нежелательный эффект. Координата x = состояние изделия,
λ ↔ свойство инструмента, μ ↔ свойство Х-элемента.

## S-кривая и скоростная инновация

Развитие любой системы идёт по S-кривой: I — медленный рост (новое тормозит
старое), II — быстрый рост (противоречия преодолены), III — насыщение (система
стареет, силы уходят на борьбу с новым). В конце III этапа — **бифуркация**:

- движение по ветви 3 = **усовершенствование** (сопротивление катастрофе) — даёт
  убывающую отдачу;
- движение по ветви 1→2 = **овладение катастрофой**: переход к новому делу /
  процессу / продукту с качественно новым свойством, сильно превышающим старое.

**Скоростная инновация** = резкий скачок свойства производственно-экономической
системы (переход к новой S-кривой), а не плавная оптимизация на старой.

## Как строить модель (рецепт)

1. **Выбери потенциальную функцию** — величину, которую система минимизирует:
   издержки/затраты (норм. фирма их снижает), время процесса, вероятность отказа.
   «Хорошая» катастрофа = переход в более глубокую яму (меньше издержек). «Плохая»
   катастрофа (например по прибыли как потенциалу) = сваливание в худшую яму — её
   надо предотвращать.
2. **Выбери координату x** — фактор, влияние которого исследуешь (выпуск, цена,
   вероятность события…).
3. **Выбери два управляющих параметра**: один **внутренний** (решения фирмы:
   инвестиции, обучение, перестройка структуры, затраты на разработку), один
   **внешний** (среда: стоимость сырья, налоги, действия конкурентов, погода/спрос).
4. **Найди критическую полосу** значений внешнего параметра, где при фиксированном
   внутреннем возможны ОБА состояния (старое и новое) — это и есть зона скачка
   (бифуркационная диаграмма). Меняя внутренний параметр, ты деформируешь полосу:
   усилив «напряг» (инвестиции/мощность), можно сместить порог и **организовать**
   нужный скачок, преодолев холм неустойчивости.

Вывод для рекомендаций: чтобы запустить скоростную инновацию, нужно не просто
давить на один рычаг, а вывести пару (внутренний×внешний) в закритическую
область, обеспечив энергию/ресурс на преодоление холма (барьера перехода).

## Флаги катастроф (диагностика: грядёт ли скачок)

Признаки того, что система близка к катастрофе / способна на скачок:
1. несколько различных устойчивых состояний;
2. неустойчивые состояния, из которых система выводится слабыми «толчками»;
3. быстрое изменение системы при малых изменениях внешних условий;
4. необратимость (нельзя вернуться к прежним условиям тем же путём);
5. гистерезис (возврат в старое состояние дороже, чем был переход в новое);
6. «критическое замедление» (много усилий — почти нет изменений: система у барьера);
7. большой разброс результатов при одинаковых усилиях.

Если в задаче видны эти флаги — почти наверняка плавной оптимизацией не обойтись,
нужна стратегия управляемого скачка.
