# LT-базис Бартини: аналитический поиск свойств Х-элемента

Читай этот файл на Шаге 4 — для сильных инженерно-физических задач, когда нужно
определить **природу** Х-элемента аналитически, а не угадыванием. Метод кодирует
конфликтующие физические свойства размерностями в базисе длины L и времени T и
находит класс решения на пересечении трендов таблицы Бартини.

> Это самый продвинутый и нишевый блок. Применяй, когда конфликтующие свойства
> физически измеримы (длина, температура, давление, скорость, расход…). Для
> бизнес-/организационных задач он обычно не нужен.

## Идея

После 1-й части АРИЗ у нас есть ТП с двумя конфликтующими свойствами и образ
неизвестного Х-элемента. Аналогия: розыск преступника. Сначала ищем «по
действиям» (что инструмент делает изделию — глаголы, это ТП). Потом «по приметам»
(какие физические свойства у Х-элемента — это ФП). LT-базис формализует переход
от ресурсов к **физическому свойству** Х-элемента через комбинирование
размерностей.

## Система кинематических величин Бартини

Все величины выражаются как **LⁿTᵐ** (метр и секунда — базис). Физически
реализуемо в 3D-пространстве при |n+m| ≤ 3. Таблица: ось L — горизонтально, ось
T — вертикально; её можно продолжать в любую сторону.

Ключевые размерности:

| Величина | LT-размерность |
|---|---|
| Длина | L¹T⁰ |
| Поверхность (площадь) | L²T⁰ |
| Объём | L³T⁰ |
| Скорость | L¹T⁻¹ |
| Ускорение / напряжённость гравиполя | L¹T⁻² |
| Масса | L³T⁻² |
| Объёмный расход (м³/с) | L³T⁻¹ |
| Массовый расход / ток | L³T⁻³ |
| Сила | L⁴T⁻⁴ |
| Давление | L²T⁻⁴ |
| Энергия = стат. температура (пост. Больцмана безразмерна) | L⁵T⁻⁴ |
| Удельный вес | L¹T⁻⁴ |
| Динамическая вязкость | L²T⁻³ |
| Эл. заряд | L³T⁻² |
| Эл. ток | L³T⁻³ |

В системе Бартини почти все мировые константы безразмерны (кроме скорости света
и ускорения свободного падения). Это значит: восстановленная из размерностей
формула верна **с точностью до постоянного безразмерного множителя**.

## Три тренда таблицы

- **Строки** = пространственные тренды (фиксировано T, меняется L);
- **Столбцы** = временные тренды (фиксировано L, меняется T);
- **Диагонали** = тренды ВПР (вещественно-полевых ресурсов); на диагонали сумма
  S = n+m постоянна. «Родительский» тренд передаёт Х-элементу значение S от
  конфликтующих свойств-«родителей».

Решение Х-элемента ищется **на пересечении** пространственного, временного и
ВПР-трендов.

## Логика «И-И» и баланс размерностей

В отличие от выбора ИЛИ-ИЛИ в ТП, здесь действует логика **И-И**: оба
конфликтующих фактора должны быть «хорошими» одновременно. При «И-И» размерности
факторов **перемножаются**:

```
Lⁿ¹Tᵐ¹ = C · (размерность фактора 1) · (размерность фактора 2)
```

где C — произведение размерностей неучтённых факторов (по умолчанию C = L⁰T⁰).

## Канонический пример: запайка ампул с лекарством

**НЭ:** длинный язычок пламени перегревает лекарство; короткий — плохо запаивает
капилляр. Инструмент = язычок пламени, изделие = ампула.

1. **Пространство.** Состояние изделия — длина капилляра, L¹T⁰. Геометрия
   инструмента (поверхность контакта) на единицу больше — L²T⁰. Значит Х-элемент
   должен быть на единицу больше инструмента — **объём, L³T⁰** (тренд
   «точка→линия→поверхность→объём»). Вывод: Х-элемент — это объём, а не точка/линия.
2. **Время.** Решение лежит где-то в столбце L³Tᵐ (двигаемся по временно́му тренду).
3. **ВПР (И-И).** «И» длина капилляра хорошая (L¹T⁰), «И» температура оплавления
   хорошая (L⁵T⁻⁴). Перемножаем:
   `Lⁿ¹Tᵐ¹ = C·L⁵T⁻⁴·L¹T⁰`. При C=L⁰T⁰ → **L⁶T⁻⁴** (родительский тренд S=+2).
   Пересечение родительского тренда с временны́м столбцом L³Tᵐ даёт клетку
   **L³T⁻¹ = м³/с = объёмный расход**.
4. **Решение:** Х-элемент — **расходуемый объём**. Физически: ампулы ставят в воду,
   которая испаряется и отводит тепло; воду надо добавлять, лучше проточную. Прямого
   указания «вода» нет — охладителем может быть и другая жидкость, газ, лёд. Решение
   получается **на качественном уровне** (класс решения, а не рецепт).

## Численная оценка: формула связи ресурсов

Если процесс установившийся, дифуравнения тепломассообмена вырождаются в
алгебраическую связь. Достраивая баланс размерностями свойств Х-элемента
(объём V, удельная объёмная теплоёмкость U, динамическая вязкость W, энергия
пламени Э, КПД η, постоянная Больцмана B), для примера запайки получаем:

```
R = B·η·Э / (V·U·W)
```

где R — объёмный расход охладителя. Формула верна **с точностью до постоянного
множителя** (не учитывает безразмерные константы вроде числа Авогадро), но даёт:
- **прямые/обратные пропорциональности** ресурсов (что растёт — что падает);
- связь пространственных ресурсов с вещественными;
- зафиксировав часть величин, получаешь связь между остальными.

Например: чтобы минимизировать расход охладителя, выбирай вещество с **максимальным
произведением U·W** (объёмная теплоёмкость × вязкость). Подбор такого Х-элемента
формально сводится к задаче **нелинейного программирования** (Лагранжа — при
ограничениях-равенствах, Куна–Таккера — при неравенствах): минимум расхода/объёма/
массы Х-элемента при ограничениях на его свойства-константы.

## КПД Х-элемента (мера идеальности решения)

Чтобы сравнивать решения РАЗНЫХ задач в рамках АРИЗ, вводится коэффициент
полезного действия Х-элемента:

```
η = D / (Y_K + D)
```

- **Y_K** — усиление конфликта: выбор крайнего состояния инструмента (шаг 1.5 АРИЗ);
- **D** — действие Х-элемента по устранению вреда (шаг 1.6).

Трактовка: если задача решена уже на шаге 1.5 (предельным усилением инструмента),
Х-элемент не нужен и η = 0 — это идеал. Чем больше приходится «доделывать»
Х-элементом (больше D), тем больше η и тем **менее** идеально решение.
**Чем меньше КПД Х-элемента, тем идеальнее решение.** В задаче о запайке η ≈
(энергия охлаждения) / (энергия горелки). Для других задач — отношение объёмов,
масс и т.п., характеризующих состояние инструмента в ТП.

## Алгоритм применения (кратко)

1. Запиши конфликтующие свойства ТП размерностями LⁿTᵐ.
2. Найди пространственный тренд Х-элемента (обычно +1 к геометрии инструмента).
3. Найди временной столбец Х-элемента.
4. Перемножь свойства (логика И-И) → родительский ВПР-тренд (S=n+m).
5. Пересечение трендов = клетка размерности → **класс решения** (расход, давление,
   объём, поле…).
6. (Опц.) Дострой баланс свойствами Х-элемента → формула связи ресурсов (с точностью
   до константы) → пропорциональности и задача оптимизации.
7. Оцени КПД Х-элемента — насколько решение близко к идеалу.
